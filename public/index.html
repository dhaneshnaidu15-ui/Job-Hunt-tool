What this version does — and does not — do

It searches Remotive's public remote-job feed on demand and any company Greenhouse boards you configure, scores postings, deduplicates records, filters expired postings when a closing date is supplied, flags missing qualifications and uncertain salaries, tailors fact-based resume content, and maintains a browser-local tracker.

It does not run while your browser is closed, scrape all company sites, verify that external URLs return successful responses, auto-submit forms, bypass captchas, log in to employer accounts, or create a public hosting URL. An always-on application agent requires a hosted backend, compliant job-source access, candidate authorization, and employer-specific application integrations.
